# PortSwigger Web Security Academy Notes

This repository contains my personal notes, payloads, and walkthroughs for the PortSwigger Web Security Academy labs.

##  Structure
- `01-SQL-Injection/` - UNION attacks, Blind SQLi, Error-based SQLi.
- `02-XSS/` - Reflected, Stored, DOM-based.
- `03-CSRF/` - Token bypasses, SameSite cookies.
- `04-Authentication/` - Brute force, logic flaws.

##  Goal
To document every lab completed to reinforce my understanding of web vulnerabilities.
